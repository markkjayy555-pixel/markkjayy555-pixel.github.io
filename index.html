🤔 What is Panel?

Panel is a research workspace where an AI agent works right beside you. It's like having a smart assistant who can:

  • 💬 Chat with you about your research
  • 📁 Manage and organize your files
  • 📄 Read and analyze PDF documents
  • 📓 Work with notebooks for data analysis
  • 🛠️ Create custom viewers and apps when you need them

Think of Panel as your personal research hub where you and AI work together seamlessly. It's currently an early build for testers, so you might encounter some rough edges - but that's part of the adventure!

🔧 What You'll Need Before Starting

Don't worry - these are just a few free tools that Panel needs to run. Each one is easy to install:

1️⃣ Node.js - A platform that runs JavaScript. You need version 22.18 or newer (or 24.12 and newer). Download Node.js here

2️⃣ pnpm - A package manager that helps Panel install its parts. Install pnpm here

3️⃣ uv - A tool that fetches Python for you automatically. Get uv here

4️⃣ Claude Code - The AI brain behind Panel. Set up Claude Code - just run claude once and log in.

🚀 Getting Started

Once you have the tools above installed, follow these simple steps:

Open your terminal (Command Prompt on Windows) and type:

pnpm install
uv sync
pnpm start

Then open your web browser and go to http://localhost:4173

💡 Note: The first start takes about a minute because Panel builds itself first. To stop Panel, press Ctrl-C in the terminal.

📁 Where Your Things Are Stored

All your work is saved automatically. You'll find your data in a special folder on your computer:

~/Panel/panel.db

This file holds all your conversations, files, and projects. You can back it up by copying this file to another location.
